# Campus Companion 🎓

Campus Companion is a holistic student productivity and wellness web application built with Flask and AI to help college students navigate academic hurdles, burnout, and personal growth.

## Features
- **Deadline Tracker:** Keep track of assignments, exams, and important academic dates so nothing slips through the cracks.
- **Check-ins:** Daily status and attendance tracking to stay on top of routines.
- **Personality Tracker:** Reflect on personal traits, strengths, and behavioral patterns.
- **Self-Development Hub:** Tools to set personal goals, build better habits, and track growth.
- **Mental Health & Well-Being:** A dedicated space for stress management and emotional check-ins to prevent burnout.
- **AI Backend:** Powered by Flask and backend API calls for intelligent features.
